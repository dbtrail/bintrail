================================================================================
THIRD-PARTY NOTICES
================================================================================

bintrail (and the bintrail-mcp, bintrail-console and bintrail-pg binaries
published from this repository) statically links a number of third-party Go
modules and, through the precompiled libduckdb static library, a number of
vendored C/C++ libraries.
The licenses below are reproduced to satisfy their notice-retention terms.

This file has two parts:

  1. A MANUAL section, maintained by hand, covering components that the
     automated tooling cannot see: the C/C++ libraries vendored inside the
     precompiled libduckdb static library, a note on the one weak-copyleft
     dependency (go-sql-driver/mysql, MPL-2.0), and the OFL-1.1 web fonts
     embedded in the bintrail-console binary.

  2. A GENERATED section, produced by `make notices` (which runs
     `go-licenses save` over ./cmd/bintrail, ./cmd/bintrail-mcp,
     ./cmd/bintrail-console and ./cmd/bintrail-pg), reproducing the LICENSE
     — and, where present, the NOTICE — file of every linked Go module.

Regenerate with `make notices`. Do not edit the GENERATED section by hand.

================================================================================

--------------------------------------------------------------------------------

github.com/go-sql-driver/mysql is licensed under the Mozilla Public License
Version 2.0 (MPL-2.0), a weak (file-level) copyleft license — not MIT/BSD. Its
full license text appears in the GENERATED section below.

bintrail uses this module UNMODIFIED, so the obligations are light:

  - retain this notice (satisfied by including the MPL-2.0 text in this file);
  - keep the corresponding source available. The unmodified source is the
    public upstream module at https://github.com/go-sql-driver/mysql (pinned in
    this repository's go.mod), which is the source location offered for the
    Covered Software.

MPL-2.0 is file-scoped: it does NOT require bintrail itself to be open-sourced.
Only if a `.go` file within this module were ever modified would that specific
modified file have to be published under the MPL.
